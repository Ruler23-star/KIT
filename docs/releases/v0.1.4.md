# KIT v0.1.4

发布日期：2026-11-25。对比基线：v0.1.3（9dd8e4e）。

## 新增功能

### 明暗主题切换

点击侧栏 KIT 图标切换主题，选择保存在本机。新增深色编辑器、日历、图片管理与主要弹窗配色；浅色高亮背景使用深色文字，工具栏下拉选项适配深色。

### 富文本多图片对比

工具栏新增双图片图标，在光标处插入堆叠组件。管理浮窗支持最多 30 张真实上传图片，每张图片独立保存标签和说明，可替换、删除、排序并重新编辑。

点击缩略图定位到该图片的扇形展示。左右按钮、方向键、滚轮可循环切换；按住鼠标左右滑动也可连续切换，到首尾停止。切换直接完成，无过渡动画。图片完整显示，标签随卡片绑定，底部说明区预留固定高度，展示浮窗适配窗口高度。

### 侧栏文章快捷方式

文章列表支持拖到整条蓝色侧栏，生成彩色圆点。单击打开，悬停放大并显示标题，双击移除快捷方式后打开下一个（末尾则打开上一个）。原文章不删除。圆点只沿竖直方向拖动，支持交换位置和间隙插入提示；颜色绑定文章，删除其他圆点不改色。

### 持续任务单日取消

周日历卡片悬停显示小叉，取消该日期的展示，而非结束整个任务；后续日期继续。排除日期持久化，同步今日任务、主页月历及任务月历。取消和日程调整接入最近三步撤销。

## 体验和修复

- 普通图片和对比节点支持嵌入、居中、并排与上下拖放，添加统一插入提示和可持久化换行节点。
- 正文默认 16px，提供四种文字对齐；格式按钮不因悬停高亮，点击后及时反映格式状态。
- 连续空格在 HTML 加载时保留；拖选正文自动下滚提速。
- 调整外部内容加载时序，避免 React 生命周期内创建节点视图引发同步渲染冲突。
- Todo、灵感标题可直接编辑；任务标题停止输入后自动保存，关闭详情也提交最新草稿。
- 文件夹可从编辑弹窗删除，文档和子文件夹沿用现有删除逻辑移至顶层。
- 调整部分英文文案、标题字体、状态色和按钮布局，移除“今日自动延续”等提示。
- 文档列表改按创建时间排序。

## 数据兼容与存储

- SQLite 自动为已有任务表添加 excluded_dates 字段，默认空数组。
- 多图片组件与换行节点随知识正文 HTML 保存；图片沿用本地上传资源。
- 快捷圆点顺序、颜色和主题使用本机 localStorage，不是 GitHub 云同步数据。
- 本次上传源码与版本说明，不上传个人数据库、文章内容、上传图片或本机偏好。
