# KIT

**Knowledge · Idea · Todo**

当前版本：**v0.1.3**

KIT 是一个本地优先的个人知识与行动工作台。它不只保存信息，而是把阅读、知识、灵感、任务、日历与复盘串成一条能够持续运转的个人工作流。

> 让知识不止被收藏，让想法最终走向行动。

## 产品理念

```text
记录知识 → 捕捉灵感 → 转化 Todo → 安排日历 → 执行与复盘 → 回写知识
```

知识文档、灵感、任务、来源关系和上传图片默认保存在本机。每个模块可以独立使用，也可以通过来源关系互相连接，让一个想法从“为什么产生”到“如何行动”始终可追溯。

## v0.1.2 更新内容

### 全新的主页月历

- 主页加入完整月日历，保留每日任务状态方块

- 清明、中秋、冬至等日期使用独立主题原画；春节、除夕、元宵、端午、国庆等节日也分别使用不同画面
- 节日与节气名称使用放大的书法感字体，日期与任务信息始终显示在插画上层
- 今日日期使用醒目的楷体，并保留任务完成进度环

### 更紧凑的工作区

- 删除今日任务、知识记录、灵感记录和 Todo 页面重复的顶部标题栏，让内容获得更多垂直空间
- 删除侧栏全局搜索框，减少视觉干扰
- 侧栏支持拖动右侧边框在“展开”和“收缩”两档间切换
- 收缩后只保留 KIT 图标、导航图标与当前页面高亮；向右拖动即可恢复完整导航

### Todo 与日历交互优化

- 日历中的任务可以直接拖回整个左侧任务栏，取消当天安排并自动恢复为灰色“未安排”状态
- 从左侧删除任务时，会同步彻底清除日历中的对应安排
- 点击左侧任务卡片即可打开编辑详情，不再依赖独立编辑按钮
- 任务描述和任务结果支持自动保存，并针对中文输入法组合输入做了保护
- “保存并完成”调整为更明确的“保存并结束任务”
- 灵感转为 Todo 时只进入“全部事项”，不会自动加入今日任务
- 周日历内已完成任务自动集中到每天顶部；左侧任务库将未完成任务置顶、已完成任务集中到底部

### 知识与灵感细节优化

- 知识文档列表不再显示“几天前”，改为显示文章标签；无标签时保持留白
- 删除新建知识文档后的冗余提示
- 灵感草稿和 Todo 详情草稿在离开页面或重新打开后仍然保留
- 灵感卡片默认仅展示标题和标签，点击后居中展开完整内容
- 灵感展开和收起使用约 `0.3s` 过渡动画，点击周围空白区域自动收起
- 灵感支持编辑、删除以及转化为 Todo

## 全部功能

### 今日任务与主页

- 快速创建今日任务并显示完成进度
- 今日任务支持直接勾选完成或恢复未完成
- 每天自动生成“某年某月某日晨报”待办，默认位于今日列表底部
- 当日未安排的晨报会在次日自动清理；已安排的晨报会一直保留
- 主页月历汇总任务状态、传统节日、节假日和二十四节气
- 提供知识记录、灵感记录、Todo 和知识框架的快捷入口

### 知识记录

- 类 Word 富文本编辑器，支持标题、字号、粗体、斜体、删除线、引用、列表和文字高亮
- 支持软换行、段落标记和接近 Word 习惯的换行符显示
- 支持插入图片、自由缩放、嵌入型或文字环绕布局
- 图片提供 Word 风格裁剪模式，可拖动四边及四角控制柄
- 正文区域独立纵向滚动，长文编辑时工具栏保持可见
- 支持一键进入正文全屏模式，并可按 `Esc` 退出
- 优化文字拖动选择：普通选择不会带动页面快速跳动，抵达可视区域底部后才会缓慢滚动
- 针对中文输入法优化组合输入，避免残留重复拼音或打断候选词
- 正文内容自动保存
- 多级文件夹和知识文档树，可新建文档、文件夹与子文件夹
- 支持文件夹重命名、文档快捷删除和长标题悬停预览
- 文档栏与来源栏可折叠，文档区域可拖动调整宽度
- 可维护来源类型、来源名称、URL、作者与标签
- 支持手动标签和 AI 生成标签

### 灵感记录

- 随时捕捉原始想法，未提交草稿也会自动保留
- 卡片默认仅展示完整标题和标签，避免长正文挤满页面
- 点击卡片后自动移动到屏幕中央并展开详细内容
- 支持修改标题、正文、标签以及删除灵感
- 保留灵感与来源知识文档、引用原文之间的关系
- 可将灵感一键转化为未安排 Todo

### Todo 任务库

- 左侧集中管理全部任务，支持全部、今天、进行中和已完成筛选
- 状态颜色统一：灰色为未安排、黄色为未开始、红色为进行中、绿色为已完成
- 点击任务卡片直接打开完整编辑页面
- 支持修改标题、描述、状态、今日任务设置和任务结果
- 描述与结果输入自动保存，并兼容中文输入法
- 任务可追溯到来源知识或灵感
- 完成后的结论可以回写原知识文档
- 删除左侧任务会同时移除其所有日历安排

### 周日历与月日历

- 支持周视图与月视图自由切换
- 周视图按天展示详细任务，不强制安排一天中的具体时间
- 月视图使用彩色任务方块显示每天的任务状态
- 可点击任务右侧日历图标，通过悬浮日期选择器安排任务
- 可直接把左侧任务拖入周日历的某一天快速安排
- 可在周日历内拖动任务调整日期
- 可把日历任务拖回整个左侧任务栏取消安排，无需寻找可见删除区
- 进行中且未完成的任务只会在第二天自动延续，不会提前铺满未来所有日期
- 已完成任务在每日任务列中自动置顶

### 知识框架与 AI 协作

- 通过知识树展示文档、标签、灵感及其来源关系
- 汇总知识数量、灵感节点和知识到行动的连接
- 可从正文选中文字生成灵感或 Todo
- 支持调用 ChatGPT/Codex 对选中文字进行总结、解释、润色、提出问题或提取行动
- 可让 AI 梳理文章灵感、发现知识缺口、给出下一步建议和行动方案
- AI 生成内容与用户原始记录分离，最终写入由用户确认

### 本地优先与数据安全

- 知识、灵感和 Todo 使用本地 SQLite 数据库存储
- 上传图片保存在本机数据目录
- 用户数据库、上传内容和备份不会随源码上传到 GitHub
- 普通浏览器可以使用全部非 AI 功能
- Windows 桌面版提供独立安装包

## Windows 安装

前往仓库右侧的 **Releases**，下载最新的 `.exe` 安装包，运行后按照安装向导完成安装。升级或卸载前建议先备份个人数据。

## 从源码运行

需要 Node.js 和 pnpm：

```powershell
pnpm install
pnpm dev
```

然后访问 `http://localhost:3000`，也可以在 Windows 中双击 `启动工作台.bat`。

## 构建桌面安装包

```powershell
pnpm install
pnpm desktop:build
```

安装包生成在 `dist` 目录中。

## 本地开发数据

- SQLite 数据库：`data/knowledge.db`
- 图片：`data/uploads/`
- 备份目录：`data/backups/`

这些实际数据已经通过 `.gitignore` 排除，不会被提交到代码仓库。
