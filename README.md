# KIT

**Knowledge · Idea · Todo**

当前版本：**v0.1.1**

KIT 是一个本地优先的个人知识与行动工作台。它希望解决的不是“把信息存下来”这一件事，而是让知识、灵感和行动真正连接起来：从阅读与记录中沉淀知识，从知识中产生灵感，再把灵感转化为可以安排、执行和复盘的 Todo。

> 让知识不止被收藏，让想法最终走向行动。

## 产品理念

KIT 围绕一条持续循环的个人工作流设计：

```text
记录知识 → 产生灵感 → 转化 Todo → 安排日历 → 执行与复盘 → 回写知识
```

所有知识文档、灵感、任务、来源关系和上传图片默认保存在本机。你可以独立使用各个模块，也可以让它们通过来源关系组成一套能够追溯的个人知识系统。

## 本版新增功能

- 优化中文输入法兼容性，正文编辑时不再残留未确认的拼音字母
- 正文改为独立纵向滚动，长文编辑时工具栏保持可见，并支持一键进入正文全屏模式或按 `Esc` 退出
- 优化拖动选择文字的行为：选择过程中页面不会突然跳动，只有到达可视区域最后一行后才会缓慢向下滚动
- 图片新增 Word 风格裁剪模式，支持拖动四边和四角控制柄，并保留原有自由缩放与文字环绕设置
- 每天自动生成一条“某年某月某日晨报”待办，默认位于“今天”列表底部；当天未安排则次日自动清理，已经安排过的晨报会保留

## 已实现功能

### 知识记录

- 类 Word 的富文本编辑器，支持标题、粗体、斜体、删除线、列表、引用、字号和文字高亮
- 支持插入图片、自由调整图片宽高、Word 风格裁剪，并设置嵌入型或文字环绕布局
- 多级文件夹与知识文档树，可在指定目录新建文档或子文件夹
- 文件夹重命名、文档快捷删除、长标题悬停预览
- 文档栏和来源栏可折叠，文档区域可拖拽调整宽度
- 记录来源类型、来源名称、URL、作者和标签
- 支持手动维护标签及 AI 生成标签
- 正文区域独立滚动并支持全屏编辑，工具栏在长文记录时保持可见
- 编辑内容自动保存，并优化中文输入法和文字拖选体验

### 灵感记录

- 随时捕捉原始想法，并在离开页面后保留未提交草稿
- 灵感卡片以标题和标签概览展示
- 点击卡片后居中展开详细内容，支持编辑和删除
- 保留灵感与来源知识文档、引用原文之间的关系
- 可将灵感一键转化为 Todo

### Todo 与日历

- 左侧集中管理全部任务，右侧通过日历查看任务安排
- 支持周视图和月视图
- 使用颜色区分未安排、未开始、进行中和已完成状态
- 可通过日期选择器或拖拽把任务安排到某一天
- 可将日历任务拖入取消安排区域，同时保留原任务
- 进行中的未完成任务会在下一天自动延续，而不会预先铺满未来日期
- 每日自动生成晨报待办；未安排的晨报次日自动清理，已安排的晨报永久保留
- 任务可追溯到对应知识或灵感，完成结果可回写原知识文档

### 知识框架与 AI 协作

- 通过知识树展示文档、标签、灵感及其来源关系
- 汇总知识数量、灵感节点和知识到行动的连接
- 可从选中文字生成灵感或 Todo
- 可调用 ChatGPT/Codex 对选中文字进行总结、解释、润色、提出问题或提取行动
- 支持让 AI 分析知识主题、发现知识缺口和提出下一步行动建议
- AI 生成内容与用户原始内容分离，保存操作需要用户确认

### 本地优先

- 知识、灵感和 Todo 使用本地 SQLite 数据库存储
- 上传图片保存在本机数据目录
- 数据不会随源码上传到 GitHub
- 普通浏览器可使用全部非 AI 功能

## Windows 安装

在仓库右侧的 **Releases** 页面下载最新的 `.exe` 安装包，运行后按照安装向导完成安装。

首次启动后，KIT 会在本机创建独立的数据目录。卸载或升级应用前，建议先备份其中的数据。

## 从源码运行

需要预先安装 Node.js 和 pnpm：

```powershell
pnpm install
pnpm dev
```

然后访问 `http://localhost:3000`，也可以在 Windows 中双击 `启动工作台.bat`。

## 构建桌面安装包

```powershell
pnpm install
pnpm desktop:build
```

构建完成后，安装包会生成在 `dist` 目录中。

## 本地开发数据

- SQLite 数据库：`data/knowledge.db`
- 图片：`data/uploads/`
- 备份目录：`data/backups/`

这些实际数据已经通过 `.gitignore` 排除，不会被提交到代码仓库。

## 当前状态

KIT 仍处于早期开发阶段。功能、数据结构和安装方式可能继续调整，建议在升级前备份个人数据。
